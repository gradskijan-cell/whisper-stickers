# Стикеры для «Шёпота»

Этот репозиторий сам скачивает паки стикеров из Telegram и складывает их сюда. «Шёпот» берёт стикеры отсюда: ты отправляешь их из панели смайликов, а бот выбирает их по подписям.

Анимированные стикеры, видеостикеры и гифки становятся анимированными картинками WebP. Прозрачный фон сохраняется.

## Один раз: настройка (10 минут)

### 1. Аккаунт и репозиторий
1. Зайди на **github.com** → **Sign up**: почта, пароль, имя пользователя. Подтверди почту.
2. Справа вверху **＋** → **New repository**.
   - Repository name: `whisper-stickers`
   - Выбери **Public**. Это обязательно: иначе «Шёпот» не увидит картинки.
   - Поставь галочку **Add a README file** и нажми **Create repository**.

### 2. Файлы
1. В репозитории: **Add file** → **Upload files**. Выбери `build_stickers.py`, `packs.txt` и этот `README.md`, затем нажми **Commit changes**.
2. **Add file** → **Create new file**.
   - В поле имени набери ровно `.github/workflows/stickers.yml`. После каждого `/` GitHub сам создаст папку.
   - Вставь в большое поле весь текст из файла `stickers.yml` и нажми **Commit changes**.

### 3. Бот Telegram (нужен только для скачивания паков)
1. В Telegram открой **@BotFather** → `/newbot` → придумай имя и username, который заканчивается на `bot`.
2. BotFather пришлёт **токен** вида `123456:ABC…`. Никому его не отправляй, даже в чат с Claude.

### 4. Токен — в секреты репозитория
В репозитории: **Settings** → **Secrets and variables** → **Actions** → **New repository secret**.
- Name: `TELEGRAM_BOT_TOKEN`
- Secret: токен от BotFather
- Нажми **Add secret**.

На телефоне вкладка **Settings** может прятаться в меню «⋯». Если её нет, открой сайт в режиме «Версия для ПК».

## Добавить паки

**Способ А.** Вкладка **Actions** → слева **Стикеры для Шёпота** → **Run workflow** → вставь ссылку или ссылки `https://t.me/addstickers/…` → **Run workflow**.

**Способ Б.** Открой `packs.txt` → ✏️ → допиши ссылку новой строкой → **Commit changes**. Сборка запустится сама.

Через 1–3 минуты в репозитории появятся папка `stickers` и файл `stickers.json`. Зелёная галочка в **Actions** значит, что всё готово. Если стоит красный крестик, открой запуск: внизу шага будет написано, что не получилось.

Ссылку на пак берут так: в Telegram нажми на стикер → откроется пак → **Поделиться** → **Копировать ссылку**.

## Гифки
Создай файл `gifs/readme.txt` с любым текстом: так появится папка `gifs`. Потом открой эту папку → **Add file** → **Upload files** и загрузи `.gif` или `.mp4`.

Называй файлы по смыслу, например `обнимашки.gif` или `закатила-глаза.mp4`. Имя файла станет подписью, и бот поймёт, что это.

## Подключить к «Шёпоту»
⋮ → ⚙️ **Настройки** → 🧸 **Стикеры** → вставь ссылку на репозиторий (`https://github.com/твоё-имя/whisper-stickers`) → **Загрузить стикеры**.

Паки появятся вкладками в панели смайликов 😊 и в 📎 → **Стикеры**.

## Как бот понимает стикеры
Бот не видит картинку, он читает подпись. Подписи лежат в `stickers.json` в поле `desc`. Сначала там эмодзи из Telegram, например `"desc": "😭"`.

Чтобы бот выбирал точнее, открой `stickers.json` → ✏️ и замени подписи словами, например `"desc": "котик плачет навзрыд"`. Твои подписи сохраняются при следующих сборках.

Убрала строку из `packs.txt` — пак удалится. Чтобы скачать всё заново, отметь **Скачать все паки заново** в **Run workflow**.
